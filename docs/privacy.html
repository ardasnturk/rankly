Privacy policy

Your data stays on your Mac.

The short version: Rankly has no account, no analytics, no tracking and no server. The developer never receives your data.

Summary

This policy covers the Rankly macOS app and this website (rankly.ardasnturk.com). Both are operated by Arda Sentürk (“we”, “the developer”).

  • No account or sign-in.
  • No analytics, no tracking, no advertising, no cookies in the app.
  • The developer runs no server and receives no data from the app.
  • Everything you track is stored locally on your Mac.

What we collect

Nothing. Rankly does not collect, transmit, sell or share any personal data with the developer or with any third party for analytics or advertising. There is no crash reporting or telemetry built into the app.

Network requests the app makes

To work, Rankly connects directly from your Mac to only these services:

a) Apple App Store

Rankly uses Apple's public App Store endpoints at search.itunes.apple.com (search ranking and autocomplete suggestions) and itunes.apple.com (app lookup). These requests contain only what is needed for the lookup: search terms, App Store app IDs and storefront/country codes.

Like any App Store request, Apple can see your IP address. Apple's own privacy policy applies to these requests. Rankly is not affiliated with Apple.

b) Update checks

Rankly uses the Sparkle framework to check for updates. It downloads the update feed https://rankly.ardasnturk.com/appcast.xml (hosted on GitHub Pages) and, when you install an update, the update file from GitHub Releases. GitHub can see your IP address for these downloads; GitHub's privacy statement applies. No system profile or usage information is sent with update checks.

Data stored on your Mac

All tracked apps, keywords, rank history and analysis results are stored locally in the app's sandbox container:

~/Library/Containers/com.ardasenturk.rankly/

This data never leaves your Mac through Rankly. Deleting the app's container folder removes everything. See the uninstall guide.

This website

rankly.ardasnturk.com is a static site hosted on GitHub Pages. It uses no analytics and no cookies. Your language choice is remembered in your browser's local storage and never sent anywhere.

GitHub, as the host, processes server logs such as your IP address to deliver the pages. The site loads fonts from Google Fonts, so Google may receive your IP address when you visit; see Google's privacy policy.

Children's privacy

Rankly is a tool for app developers and marketers and is not directed at children. Since it collects no personal data, it collects none from children either.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date. Significant changes will also be noted in the release notes on GitHub.

Contact

Questions about privacy? Open an issue at github.com/ardasnturk/rankly/issues.
